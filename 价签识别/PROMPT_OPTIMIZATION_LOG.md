# 价签识别提示词与全图检测演进复盘记录

> 历史复盘，不是当前默认方案。服务化一期禁止默认恢复复杂切片/两阶段流程；任何切片、OCR 或定位增强都必须先通过固定样本评测。

本文档记录了基于 Mengniu Flow API 在零售商品价签（Price Tag）目标检测与识别任务中，提示词（Prompt）优化、全图模型缺陷分析以及后处理探索的全过程与经验教训。

---

## 一、原始问题与基准状态

1. **初始任务**：
   - 针对零售冷柜/货架全景图（如第一张测试图 39 个目标价签），要求满额检出并精准贴合真实价签外框。
2. **初始缺陷**：
   - 依赖前序复杂启发式合并与中位数拉扯脚本，导致 X/Y 坐标颠倒、坐标漂移到瓶盖与瓶身；
   - 全图单次调用受限于视觉下采样，对底层微小密集价签存在 1~2 个边缘漏检。

---

## 二、模型切换与坐标格式演进

1. **模型切换发现**：
   - 通用大模型（如旧版文本偏向多模态）擅长念价格，但在像素级小框定位上存在注意力漂移；
   - 专用 OCR 类模型会将连续文字按字符切片刷出 60+ 个碎片碎块；
   - 强视觉多模态模型能够稳定识别全量价签，但其返回格式存在坐标轴差异（部分模型吐 `[ymin, xmin, ymax, xmax]`，部分模型吐 `[xmin, ymin, xmax, ymax]`）。
2. **解决方式**：
   - 建立实体价签物理长宽比先验（真实价签为横向长方形，宽 > 高），根据单框长宽比自适应确定坐标系，消除了翻转为立柱细条的 Bug。

---

## 三、提示词（Prompt）迭代演进记录

### 阶段 1：死板硬性约束（反面教材）
- **旧版 Prompt 缺陷**：
  - 硬性要求“必须按第1层、第2层、第3层依次扫描”；
  - 要求“看不清价格也必须保留 bbox，price 填 null”。
- **引发灾难**：
  - 只有 1~2 层的冷柜被逼在瓶盖、瓶口、空白导轨上虚构画框；
  - 疯狂输出 `None` / `null` 假价签。

### 阶段 2：柔性引领与全场景包容
- **优化点**：
  - 明确覆盖货架、堆头、冷柜等多陈列场景，包容爆炸签、特价贴；
  - 废除硬凑三层，改为物理现实自然分配（1, 2, 3...）；
  - 增加 180 度倒插/倒悬价签翻正识别指导；
  - 严厉禁绝输出 `None` 占位框。

### 阶段 3：真实干扰项对抗（促销横幅与自回归复读机）
- **暴露的真实难题**：
  - 导轨上的长条形促销围条纸（POP，如“第二件1元 / 第二件2元 / 买一赠一”宣传带）严重误导大模型；
  - 模型在全图视角下，因自回归特性极易陷入连续打字机复读（如连续刷出十几个 5.50 或 15.90）；
  - 甚至把真实价签的价格跨区域脑补套用在促销横幅的小图例上。
- **提示词阻断**：
  - 明确下达禁令：横跨多商品的宣传横幅长纸纯属背景物料，严禁分配价签框，严禁套用价格。

---

## 四、核心技术结论与分块架构转型

1. **“全图单次识别 + 后处理补丁”的物理死穴**：
   - 全图输入时，大图被高比例下采样，微小价签只占几个像素；
   - 后处理打补丁（如限制同价频次）会误伤真实同价商品；放开限制又会导致复读机泛滥；
   - 纯靠 Prompt 无法根治自回归语言模型的注意力漂移。
2. **走向切片扫描（Tiling / Slicing）正道**：
   - 针对货架物理特性，按水平导轨带进行局部切片裁剪；
   - 局部切片内价签尺寸放大 3~5 倍，视野纯净无干扰；
   - 大模型在纯净视野下回归其最擅长的“精准目标检测+读数”，彻底杜绝复读机与错位问题。
